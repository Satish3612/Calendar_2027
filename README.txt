CALENDAR 2027 - install as an app

1. Put this whole folder online (free):
   - Netlify Drop: open app.netlify.com/drop and drag this folder in.
   - or GitHub Pages / Cloudflare Pages.
2. Open the link on the phone.
   - Android (Chrome): tap "Install app", or menu > Add to Home screen.
   - iPhone (Safari): Share > Add to Home Screen.
3. The app opens full screen and works offline after the first open.
